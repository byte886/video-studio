## 二、四类范式选用指引

### 范式① 开箱估价（卡片 02 / 03 / 04）——最贴"店主人设"，覆盖高/中/低三档客单
- **共同骨架**：报价大字钩子（待开盲盒）→ 边拆边验（证书/微距）→ 反转结论（值/赚）→ 互动 CTA。
- **按客单选节奏**：
  - 高客单（02，89BPM）：**慢、严肃、重证书**——卖信任与验真，证书逐行红框精读。
  - 中客单（03，117.5BPM）：**双品对比 + 评分清单**——让观众跟着打分，一次讲透"种 vs 色"的分歧。
  - 低客单（04，129BPM）：**轻快娱乐 + 上脖试戴 + 彩蛋**——降低门槛、引流拉完播。
- **适用**：客户寄卖/到店验货、"这条链/这颗蓝宝石值不值"选题；同一批货可按三档拍三条不同节奏。

### 范式② 蓝宝石·彩宝知识讲货（卡片 01 / 05 / 07）——与主线产品最对口
- **01 专家高货微距**：黑底硬光把宝石拍透拍馋，是"仰望级"质感模板。
- **05 产地颜色讲货**：把颜色评价拆成可教的标准，并用**火光摇曳动态微距**让"切工好"肉眼可见。
- **07 多宝项链陈列**：从中心主石到两侧配石**逐个镜头陈列**，并**翻到背面**展示工艺。
- **适用**：教顾客"怎么看你弹簧扣这颗蓝宝石"、逐部位展示金链与扣头工艺。多宝/杂宝画面不搬，只借"逐个陈列+翻背面"的动作。

### 范式③ 名石故事（卡片 06）——制造悬念与故事感
- **骨架**：黑白滤镜+惊悚大字悬念钩子 → 逐条列谜（对话框）→ 穿插史料/权威图 → 科学/理性反转 → 释然收束。
- **适用**：把"海洋之心的厄运"换成"你的蓝宝石为什么值得戴/为什么珠宝店老板自己只戴这一条"；借弧线，不搬 Hope 钻石典故与史料画面。

### 范式④ 高货项链·东方工艺（卡片 08 / 09 / 10）——成条项链，运镜可直接迁移
- **08 价值解析（129BPM 快）**：双场硬切 + 行话对比，把"贵在哪"拆成可量化知识点。
- **09 慢故事（86BPM 慢）**：慢推无台词镇场 + 借传奇资料图抬身价，是"拍自己货"氛围片最该抄的一版。
- **10 东方工艺（117.5BPM，同期声）**：深色首饰盒+黑绒+手部开盖，东方高级感道具脚本。
- **适用**：项链形态的价值拆解、氛围种草、文化高级感；翡翠/漆雕画面不搬，只借结构与道具逻辑。

## 三、片型—音频对照：知识讲货（快 BPM） vs 故事氛围（慢 BPM）

按 BPM 由慢到快排列（均为 librosa 算法估算，知识口播片 BPM 可能受语速影响、仅供参考）：

| BPM | 卡片 | 片型 | 音频特征（客观+旁证） | 呼应《音频选择与生成SOP》 |
|---|---|---|---|---|
| **86** | 09 | 慢·顶级高货故事氛围 | 镜头慢推、能量起伏、结尾留白；低频弦乐/轻钢琴最贴 | **无模特氛围片 70–100BPM 低频弦乐+轻钢琴** |
| **89** | 02 | 慢·高客单开箱验真 | 能量平稳铺满、仅结尾留白；中频主导、低频弱 | 同上（慢，让人听清专业词） |
| **103** | 06 | 中慢·名石故事悬念 | RMS 整体最低、中频极度主导（0.748）、低频垫底极弱 | 氛围/叙事，极轻垫底 |
| **112** | 07 | 中速·多宝陈列 | 能量均匀、无留白；高频占比偏高（0.290，旁证火彩闪烁） | 知识口播中快垫底（偏慢端） |
| **117.5** | 03 / 10 | 中快·对比评分 / 工艺同期声 | 03 能量偏满；10 为现场同期声、低频占比最高（0.173） | 知识口播中快垫底；器物片可走同期声 |
| **129** | 04 / 08 | 中快·轻快娱乐 / 价值解析 | 能量偏快偏满、节奏密、留白少 | 知识口播中快垫底 |
| **136** | 01 / 05 | 快·高货微距 / 颜色讲货 | 节拍最密、能量全程较满、高密度连续讲解 | 知识口播中快垫底（最快端） |

**选用原则**：
- **讲故事 / 铺氛围 / 讲高客单信任 → 用慢（约 80–105 BPM）**：低频弦乐+轻钢琴，微距留白让人声和画面呼吸（学 09/02/06）。
- **讲知识 / 拆标准 / 多镜切货 / 报价转化 → 用中快（约 112–136 BPM）**：轻量垫底不抢人声，每个硬切点给极短重音，结尾金句/CTA 做最强重音并留 0.5–1s 空白（学 01/05/08/03/04）。
- **器物/手作展示 → 可走现场同期声**（学 10）：保留手部动作与环境声，BGM 极轻或不用。
- 三档不是高低之分，是**片型之分**；同一主线产品可分别产出"慢氛围版 + 快讲货版"做 A/B。

## 四、给主线「黄金 O 字链嵌蓝宝石」的推荐组合打法

一条 30–45s 主推片，建议按下列"借点"拼装（各环节只借语言、画面全部 AI 重拍自家货）：

1. **开场微距钩子 → 学卡片 01 / 05**
   纯黑（或深蓝丝绒）底，弹簧扣处蓝宝石居中点位，顶侧硬光打刻面星芒、金面暖反光、镜面倒影，极慢推近 3s；05 的"火光摇曳"动态微距可作第 2 钩子，让切工与蓝浓度肉眼可见。
2. **价格 / 价值锚点 → 学卡片 02 / 09**
   02 的**证书逐行红框精读**（迁移为 GIA/NGTC：Natural / No indication of heating / Blue Sapphire）做硬信任；09 的**慢推镇场 + 衬线年份/成色字**做"值得被记住"的价值锚。高货用数字/成色锚，引流款用"到店试戴/私信"锚。
3. **故事感 → 学卡片 06**
   借"悬念提问→三问→反转揭晓"弧线（如"为什么珠宝店老板自己只戴这一条？"），黑白做旧可作 1–2s 开场变体；不搬海洋之心典故。
4. **多部位陈列 → 学卡片 07**
   按"弹簧扣蓝宝石 → O 字链节工艺 → 扣头结构 → **翻到背面**打磨焊接"逐个微距切，每个部位 2–4s；"背面也这么用心"建立品质信任。
5. **东方文化高级感 → 学卡片 10**
   用**深色木盒/黑绒首饰匣 + 手部开盖（不露脸）**承托金链，暖光侧打；标签式字幕（足金999·天然蓝宝石·手工抛光）像博物馆说明牌。不搬漆雕回纹画面。
6. **佩戴向往（合规）→ 学卡片 04 / 01**
   只生成**女性锁骨/颈部侧影**佩戴、随呼吸微闪，**不出正脸**（Seedance 2.0 不支持写实正脸）。
7. **收尾 → 金色大字 CTA + 最强重音 + 0.5–1s 留白**；可学 04/10 用一句提问代替叫卖，留评论钩子。

**两条成片路线（建议都做）**：
- **氛围种草版（慢，86–103 BPM）**：09 的慢推骨架 + 10 的东方道具 + 锁骨侧影，低频弦乐+轻钢琴。
- **店主讲货版（中快，117–136 BPM）**：01/05 的微距与标准拆解 + 02 的证书红框 + 07 的逐部位/背面，轻垫底+切点重音。
