# 博主成片逐帧核实 SOP v1.0

> **用途**：当博主在视频/文案里做出**效果断言**（"堪比真人实拍""人眼难辨""40 秒生成""产品一致性很好"等），需要把这些【博主一方说法】升格为可对外引用的证据时，用本 SOP 走"下载→抽帧→逐帧分析→证据档判定"全链路。
> **原则**：只记录"我们自己逐帧看到的"；帧画面给不出答案的一律标【无法判定】并说明原因；不替博主圆场、不脑补。
> **与体系挂接**：本 SOP 是《国内AI生成珠宝实操SOP》第七章"诚实清单/证据档"的执行方法；结论回填《工具选型参考》"博主宣称核验"入口；问题台账走 `03_进行中的任务/ISSUES.md`。09 只读底稿一律不改，核实结论只写进新报告/新笔记。

## 〇、一句话流程

登录态检查 → 去重检查 → 铁证法下载（或 MSE canvas 取帧/图文取图降级）→ md5+ffprobe 校验 → 按**分型**定检查维度 → 按**深度**定抽帧数量 → 逐帧分析（结论带帧号）→ 宣称逐条判定（佐证/无法判定/反证）→ 证据档升档/保留 → 写笔记+汇总报告 → 更新台账 → 文档入 git、素材不入 git。

## 一、分型 × 专属检查维度矩阵（先定分型，再选维度，不得套用单一模板）

> 不同目标的视频有不同的检查维度。**同一批视频里每一条约注分型**，报告按"分型→所用检查维度→深度→结论"组织。

| 分型 | 典型场景 | 专属检查维度 | 示例 |
|---|---|---|---|
| **产品展示/带货类** | 产品主图、展示短片、带货口播 | 珠宝质感；高光/火彩/金属反光是否物理可信；产品一致性（同品跨镜头/跨步骤不变形）；吊坠居中；链条无扭曲；分辨率清晰度 | 苞米AI演示、即梦SD2.0钻戒短片 |
| **模特佩戴/上身类** | 项链/耳饰/手链/戒指上身图、试戴教程 | 模特自然度（五官/手部/姿态）；链条无变形；佩戴位置与垂坠正确；肤色质感；产品不被抢镜；佩戴自检 4 项（链条无扭曲/五官自然/手部自然/吊坠居中垂正） | 图小东项链试戴、苞米AI佩戴图 |
| **教学/教程类** | 操作教程、发布会、工具讲解 | 信息传达（画面文字与步骤可见、字幕准确、口播与画面同步、工具名/参数可辨、操作步骤完整）；流程步骤可复现性（每步界面是否真实出现） | 周不异发布会、佩戴首饰教程、运镜词表、白底→场景→佩戴链 |
| **故事/氛围/品牌类** | 品牌大片、剧情短片、氛围广告 | 情绪弧线；镜头语言（景别/运镜/转场）；光影氛围；色彩质感；配乐与画面配合；叙事节奏；组镜顺序 | 6步AI电影级珠宝大片 |
| **知识/讲货类** | 珠宝科普、鉴别分级、避坑对谈 | 内容准确性；术语正确；实物展示清晰；鉴别/分级细节可辨（对照画面中的实物与口播字幕） | 珠宝AI落地避坑对谈 |
| **标题-正文一致性（横切维度）** | 教学/流量型**必查**；产品展示/故事型**选查** | 标题宣称 vs 画面/正文实测：一致=✅；标题夸大但正文真实=标题标「标题党·流量钩子（与正文不符）」、正文按真实内容核实；正文/画面断言被实测否定=降档「已证伪（画面实测）」；页内"标题-正文错配"逐条单列 | A2 页头"项链"正文为耳钉；即梦⑦海报未落地 |

> 混合型（如"产品展示+模特佩戴"）取两类维度的并集；至少 5 型，可按目标扩展。标题-正文一致性为横切维度，按上表必查/选查执行。

## 二、深度分级（与分型正交）

| 深度 | 动作 | 交付物 | 适用场景 |
|---|---|---|---|
| **轻量** | ffprobe 实测 + 关键帧 3-5 张，验证"存在性"与主要断言 | 每片笔记（轻量段）+ 对照表行 | 断言少、只求"有没有/大致观感"、批量初筛 |
| **标准** | 5-15 帧逐帧 + 逐条断言对照（每条带帧号） | 每片完整笔记 + 分镜/一致性对比表 | 核心宣称核对、分镜落地、产品一致性（多数案例） |
| **深度** | 关键段全帧 + 多维度评分 + 音频客观特征（librosa BPM/能量） | 评分卡 + 音频特征表 | 创作对标、配方/分镜提取、要复刻博主工作流的场景 |

> 同一批 10 条可以 3 条标准 + 7 条轻量混用；**每条笔记必须标注核实深度，不得含糊**。

## 三、防风控下载纪律（硬性）

### 3.1 前置
1. 读 `multiplatform-media-fetch/references/platforms/douyin-web-video-download.md`（铁证法原文）+ 对应浏览器自动化技能。
2. **登录态检查**：打开 `https://www.douyin.com/user/self`，页面标题含用户名=已登录；空/登录提示/验证码 = 登录墙，**立即停、移交用户扫码，不得换 URL/换号/改 cookie 硬闯**。
3. **去重检查**：按 19 位 vid 在本地素材库检索（含 content-pipeline/library 等既有库），有副本则 md5 比对后跳过。

### 3.2 铁证法（原片直下的唯一正解）
- 导航 `https://www.douyin.com/video/<vid>` → 断言页面标题含预期关键词（第一道防串闸）。
- 轮询 `video.currentSrc` 直到 URL 含 `__vid=<目标vid>`（身份铁证；约每 2s 一次、最多 ~44s，可静音播放+轻微 seek 促发真实流挂上）。
- 以 currentSrc 的 **objectid** 锚定身份，在已缓冲的 `/video/tos` 直链里筛**同一 objectid 且同一 `__vid`** 的档位取 **br 最高者**；同 objectid 必为同内容，零身份风险。
- **立即下载**（签名 URL 时效极短）：`bu.download`；超时（BU_DOWNLOAD_TIMEOUT）→ 删 `~/Downloads/未确认*.crdownload`，cell 内把直链写 `/tmp/dy_url.txt`，立刻 curl 带 Referer `https://www.douyin.com/` + Chrome UA 落盘；**绝不复用隔了几分钟的旧 URL**。

### 3.3 防风控（硬性）
- **逐条串行**，一条一个独立浏览器 cell，条间停顿 **≥32 秒**；单会话 **≤15 条**，建议每天 1-2 批。
- 撞验证码/滑块/限流：停、冷却，需验证则移交用户，不硬刚。
- 下载完成：批内 `md5 -q | sort | uniq -d` 全库唯一（有重复=串流，删错的重下）+ ffprobe 记时长/分辨率/编码；抽 1-2 帧或读转写做"名实相符"终检。

### 3.4 降级路径（2026-10-12 实测：铁证法非万能）
| 情形 | 表现 | 降级方案 |
|---|---|---|
| **MSE/DASH 分片流**（长视频/发布会/对谈常见） | `currentSrc` 恒为 `blob:`；分片 URL 无 `__vid` 身份参数，无法锚定 | **浏览器画布取帧**：导航页面 → 标题校验 → `video.currentTime` 跳转 → `canvas.drawImage(v, v.videoWidth, v.videoHeight)` → `toDataURL` 保存帧（原始分辨率帧，非下载原片）。**逐条串行、条间停 ≥32s、每次取帧前重校验标题**；记录 intrinsic 尺寸与捕获方式，笔记标注"canvas 帧（MSE 无原片）"。原片仍可再要时走 manifest 拼接（另立项，风控高） |
| **图文帖**（/video/ 重定向 /note/） | video 元素 0×0、无 /video/tos 流、只有背景乐 mp3 | **图文取图**：DOM 收集正文内容 `<img>`（naturalWidth≥300、过滤头像/推荐封面）→ curl 带 Referer 下载；核实对象改为"图片"而非"视频帧"，笔记标注"图文帖核实" |
| iesdouyin 分享页 | 仅 JS 壳（`_$jsvmprt`），无 playAddr/mp4 直链 | 不可用，不作下载来源 |

## 四、抽帧标准

- **数量随深度**：轻量 3-5、标准 5-15、深度关键段全帧。
- **关键帧选取原则**（按分型选卡点）：
  - 产品展示类：片头钩子 / 产品特写 / 高光火彩段 / 多步骤同品对比 / 片尾；
  - 佩戴类：链条特写 / 五官 / 手部 / 吊坠位置 / 多角度图；
  - 教学类：每步操作界面 / 提示词文字页（可逐字抄录） / 字幕与口播对应点；
  - 故事类：钩子 / 转场 / 情绪高点 / 组镜顺序关键帧 / 收尾；
  - 对谈类：开场 / 中段观点 / 物料展示帧 / 收尾。
- **文字类证据**（提示词页、字幕、Logo）优先抽全分辨率帧 + 正文区放大裁剪，方便逐字抄录；抄不到如实注明（画面分辨率不足/文字太小），**禁止编造**。
- 帧命名 `<vid>_<序号>_<MMSS>.jpg`；帧图本地持有、**不入 git**。

## 五、逐帧分析维度与记录规范

- 按分型矩阵选维度（见§一）；**每条结论必须带帧号**（如"F05 字幕乱码"）。
- **标题-正文一致性检查**（2026-10-12 新增）：教学/流量型必查、产品展示/故事型选查。判定规则——①标题宣称与画面/正文实测一致 → ✅已佐证；②标题夸大但正文真实交付 → 标题标「标题党·流量钩子（与正文不符）」，正文照常核实（正文≠标题时以正文为准）；③正文/画面断言被实测否定（如分镜⑦未落地、"30 秒教学"实测 41.1s）→ 从"博主一方说法"降档为「已证伪（画面实测）」；④页内"标题-正文错配"逐条单列（如 A2 提示词页头"项链"正文为耳钉），标注页头=流量钩子、正文=真实内容。
- **音频客观特征**：ffmpeg 抽 wav（-vn -ac 1 -ar 22050）→ librosa 记 BPM / RMS 能量（均值/峰值）；**人声/音乐/情绪一律标"需人工复听"**（AI 无听觉，不做主观判断）。MSE/图文无原片时标注"音频未获取，需人工复听"。
- **无法判定如实标注**，典型不可判定类：生成耗时（帧=成片，测不出工具延迟，只能口播+录屏计时）；盲测对照类（"人眼难辨/堪比真人实拍"无实拍对照件）；成本经济类（"省八成成本/不用摄影师模特"）；过程成本类（"节约抽卡成本"）；评论区内容；运营结论（"店铺可直接用"）。
- 反证同样要记（如"分镜⑦未出现：黑场+占位符"）——**核实报告不替博主圆场**。

## 六、证据档升档规则

> 沿用体系四档：已查证 / 经搜索补充 / 博主一方说法 / 未经核实。本 SOP 处理两条证据档迁移：**升档**（博主一方说法 → 已查证（逐帧实测））与**降档**（正文/画面断言被实测否定 → 已证伪（画面实测））。

| 可升"已查证（逐帧实测）" | 保持"博主一方说法/无法判定" | 降档"已证伪（画面实测）" |
|---|---|---|
| 纯画面可判且拿到帧证据：分镜落地、产品一致性（同框/同品跨步骤比对）、词表/提示词原文抄录、操作流程步骤存在、真实时长/分辨率（ffprobe/canvas 客观值）、文字/字幕内容 | 生成耗时类（帧测不出延迟）；人眼难辨/堪比真人实拍（缺实拍对照件，需另做盲测实验才能坐实）；成本/用工类；"节约抽卡成本"类过程成本；评论区领取内容；运营落地结论 | 标题/正文/分镜断言被实测否定：分镜镜头未落地（如⑦海报=黑场+占位符）、时长口径不符（如"30 秒教学"实测 41.1s）、页内标题-正文错配（页头=流量钩子、正文为真实内容）——如实记录，不掩盖不修正 |

**升档标注写法**：`已查证（逐帧实测）：<帧号/时间点> 显示 <所见事实>`；升档只写进新报告/笔记与台账，**不改 09 只读底稿原文**。升档后如需把结论回填进 SOP/工具选型正文，另走变更并记 CHANGELOG。

## 七、核实输出与台账

1. **每片笔记**：分型｜核实深度｜捕获方式（原片直下/canvas/图文）｜真实参数（ffprobe 或捕获 intrinsic + 时长）｜关键帧清单｜分型维度逐帧核查（带帧号）｜博主宣称对照（佐证/无法判定/反证+原因）｜音频客观特征｜结论与证据档建议。
2. **汇总报告**：①执行说明/下载纪律 ②逐条核实（每条注深度与分型）③宣称 vs 画面实测对照总表 ④证据档升档建议 ⑤诚实清单增量更新（哪些缺口可消、哪些新增）。
3. **台账**：ISSUES.md 对应 ISSUE 状态改"已核实（结论见报告）"+解决时间；TASK_STATUS.md 总览与下一步更新；CHANGELOG.md 记一条。
4. **仓库纪律**：mp4/帧图/wav 本地不入 git；文档走 git（先 `git pull --rebase origin main`，提交推 main；GitHub SSH 不通用 HTTPS）。

## 八、2026-10-12 ISSUE-003 实测经验（首批 10 条）

- 成功 5/10 原片直下（铁证法一次成功，hevc+aac、md5 全唯一）；分辨率实测多为 **576×1024 或 768×576**（低码率档，非高清上传——博主成片真实清晰度普遍有限，"8K/高清"类宣传需警惕）。
- 4 条 MSE 走 canvas 取帧（含一条 1440×2304 高清工作流），1 条图文帖取图 7 张；无登录墙/验证码事件。
- 高价值发现：即梦钻戒短片 7 段分镜中 6 段落地、第 7 段"品牌海报"未生成（黑场+占位符）；AI 文字跨帧崩坏（英文乱码/中文错字）为逐帧实证；佩戴教程四组提示词页逐字抄录成功且发现 2 处"标题与正文错配"；A4 工作流三阶段全部落地、同一 halo 钻戒跨阶段轮廓一致；"30 秒教学"宣称 vs 实测 41.1s 口径不符。
- 标题-正文一致性：A2 提示词页 2 处页头-正文错配（"项链"页正文为耳钉、"耳饰"页为三合一）→ 页头标「标题党·流量钩子」，正文为真实内容；即梦⑦与"30 秒教学"两类断言降档「已证伪（画面实测）」；钩子策略（可复用/避免照搬）见报告 ②-附专项。
- 结论口径：分镜落地/产品一致性（轮廓级）/词表/提示词类可升"已查证（逐帧实测）"；生成耗时、"人眼难辨"（缺对照件）、成本类维持"博主一方说法"，对外不得作效果承诺；要坐实"人眼难辨"需自拍同题材实拍 vs AI 成片做盲测（新增缺口，见 ISSUE-003 报告第⑤节）。
